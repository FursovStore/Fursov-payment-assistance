## ⚙️ Как это работает

Сайт предлагает **три простых варианта** получения ссылки на оплату Stripe — выберите тот, что удобнее для вас.

### 🔖 Вариант 1: Кнопка-закладка (Stripe)

**🏆 Рекомендуемый способ** — самый быстрый метод для десктопных браузеров.

#### Быстрый метод
1. 🖱️ **Перетащите кнопку** "Ссылка Stripe" в панель закладок браузера (зажмите левую кнопку мыши и перетащите)
2. 🌐 Откройте [chatgpt.com](https://chatgpt.com) и авторизуйтесь
3. 🖱️ **Нажмите на созданную закладку** в панели браузера (чуть ниже адресной строки)
4. ⏱️ Через 10–15 секунд появится окно со ссылкой вида `https://checkout.stripe.com/...`
5. 📋 **Скопируйте ссылку** и отправьте менеджеру

> 💡 **Подсказка:** Если панель закладок не видна — нажмите `Ctrl + Shift + B` (Windows) или `Cmd + Shift + B` (Mac)

#### Ручной метод
Если перетаскивание не работает:
1. 📋 Нажмите кнопку **"Скопировать код"**
2. ➕ Создайте новую закладку в браузере вручную
3. 📝 **Название** — любое (например, "ChatGPT Stripe")
4. 🔗 **URL** — вставьте скопированный код
5. ✅ Сохраните и используйте на сайте chatgpt.com

> 💡 **Преимущество:** Быстрый запуск прямо на странице chatgpt.com без дополнительных приложений.

---

### 💻 Вариант 2: Через консоль браузера (Stripe)

**Для технически подкованных пользователей** — использование консоли разработчика.

#### Десктопная версия
1. 📋 Нажмите кнопку **"Скопировать код для консоли"** на сайте
2. 🌐 Откройте [chatgpt.com](https://chatgpt.com) в браузере
3. ⌨️ Откройте DevTools: 
   - **Windows/Linux:** нажмите `F12` или `Ctrl+Shift+I`
   - **Mac:** нажмите `Cmd+Option+I`
4. 🖥️ Перейдите на вкладку **Console**
5. 📝 Вставьте скопированный код и нажмите `Enter`
6. 🔗 На экране консоли появится ссылка `https://checkout.stripe.com/...`
7. ✅ Скопируйте и отправьте менеджеру

#### Мобильная версия
📱 **Для Android и iOS** — доступна отдельная подробная инструкция:
- Нажмите кнопку **"Мобильная версия инструкции"** на сайте
- Следуйте пошаговым инструкциям со скриншотами
- Для Android используйте **Kiwi Browser**
- Для iOS используйте **Web Inspector**

> 💡 **Преимущество:** Понятный и прозрачный метод для тех, кто часто работает с DevTools. Работает на всех устройствах.

### 🔑 Вариант 3: Копирование ссылки (по API)

**Для тех, кто хочет поручить оформление менеджеру** — использование API-токена.

#### Шаги выполнения
1. 🌐 Откройте страницу [https://chatgpt.com/api/auth/session](https://chatgpt.com/api/auth/session) (убедитесь, что авторизованы на chatgpt.com)
2. 📋 **Скопируйте весь текст** со страницы:
   - Нажмите `Ctrl + A` (выделить всё)
   - Затем `Ctrl + C` (скопировать)
3. 📝 Вставьте скопированный текст в поле **"Вставьте API‑ответ JSON"** на сайте
4. 🔍 Нажмите кнопку **"Проверить JSON"** — данные будут проверены
5. 📨 Нажмите **"Открыть чат с менеджером"** — данные будут скопированы, и откроется Telegram
6. ✉️ Отправьте скопированные данные менеджеру для дальнейшей обработки

> 💡 **Преимущество:** Удобен, если хотите получить профессиональную помощь с оформлением подписки.
